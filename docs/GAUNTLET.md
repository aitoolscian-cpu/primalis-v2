# PRIMALIS GAUNTLET LOOP

Every meaningful implementation or visual task follows this loop.

## 1. GOAL
State exactly what we are trying to achieve.

## 2. LOCK
State what must NOT change.

## 3. BUILD
Implement only the requested task.

## 4. RUN
Run the actual game in Godot.

## 5. CAPTURE
Capture screenshots/video from the real gameplay camera.

## 6. SCORE
Score predefined criteria from 1–10.

## 7. FAIL
Identify only criteria below the required threshold.

## 8. FIX
Change only the failed areas.

## 9. REPEAT
Run, capture and score again.

## 10. SHIP
A task is complete only when:
- functional tests pass
- visual criteria pass
- performance criteria pass
- user approves the result

A large amount of work performed is NOT evidence of improvement.

Only the actual in-game result counts.
